# KR 수급 데이터는 무인증 공개 소스만 사용한다

KR 투자자별 매매동향(수급) 수집에서 pykrx(사실상 표준 라이브러리)와 KIS 등
API 키 기반 공식 소스를 의도적으로 배제하고, 무인증 공개 엔드포인트(KRX
정보데이터시스템 JSON + 네이버금융 파싱 fallback)만 사용한다. 이 저장소의
"설정 없이 바로 동작, 신규 의존성 최소화" 원칙과 TW 三大法人 fetcher 선례를
따르기 위해서다.

## Considered Options

- **pykrx**: KRX 스크래핑을 감싼 라이브러리. 결국 같은 비공식 엔드포인트에
  의존하면서 신규 의존성만 추가되고, 형식 드리프트 대응 주기가 외부 릴리스에
  묶인다 — 기각.
- **KIS(한국투자증권) OpenAPI**: 공식이고 안정적이지만 API 키 발급·설정이
  필요해 "무설정 동작" 계약을 깨고, 키 없는 사용자에게는 기능이 조용히
  비활성화된다 — 기각.

## Consequences

- 비공식 웹 엔드포인트의 형식 변경 리스크를 감수한다 — 이중 소스(KRX+네이버)
  + fail-open + network 스모크 테스트로 완화한다.
- 이후 공식 소스가 필요해지면 fetcher 내부 소스 체인에 추가하는 방식으로
  확장한다. 정규화 레코드 계약(공개 인터페이스)은 유지한다.
